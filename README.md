# Portfolio – Mohammadhossein Bikineh

Live: https://bikineh-projekts.github.io/about-me/

Handgeschriebene statische Seite für GitHub Pages: HTML, CSS und JavaScript ohne Framework, ohne Cookies, ohne Tracking.

- `tools/build.py` enthält alle Texte (Deutsch und Englisch) und erzeugt `index.html`. Texte nur dort ändern, dann `python3 tools/build.py` ausführen.
- `assets/site.css` – Gestaltung nach dem Vorbild von Bedienoberflächen in Leitwarten (ISA-101): graue Fläche, Farbe nur für Werte und Signale; heller und dunkler Modus.
- `assets/site.js` – Sprachumschaltung, interaktiver Datenweg (Steuerung → OPC → SQL → Anwendung → Analyse), vCard-Download.
- Schrift: Archivo (SIL Open Font License), selbst gehostet; Lizenz in `assets/archivo-OFL.txt`.
